# 申论日报 · 一键出图

一页纸，双栏。**整页只有一个强调色（#B2222C）**，其余层级全靠字号、字重、灰度拉开。
一份 `content.json` 进，PDF + PNG 出，页面自动铺满、绝不溢出。

两种模板，同一套视觉体系：

| `template` | 产品 | 内容形态 |
|---|---|---|
| 省略 / `daily` | **申论精读** | 一篇评论拆九段：原文逐段标注 + 拆解速览 + 句式 + 换题 + 金句 |
| `brief` | **申论早报** | 一天要闻扫一遍：5 条时政 + 会议要点 + 广东/大湾区素材 + 金句 + 数字 |

```
~/.workbuddy-ai/skills/shenlun-daily/
├── SKILL.md                 ← 本文件：怎么跑
├── references/
│   ├── DESIGN.md            ← 版式规范 + 原稿拆解 + 五个毛病与改法 + 自适应算法
│   ├── CONTENT.md           ← 精读版：九段骨架、标签词表、标记语法、字数配额
│   └── BRIEF.md             ← 早报版：每日取材口径、版式配额、各类条目写法
├── scripts/
│   ├── build.py             ← 主入口（含出厂自检）

└── examples/

```

## 一、跑起来

```bash
# 用装了依赖的那个解释器；下文用 $PY 代指
PY=python3

# 默认：在当前目录自动新建一期文件夹，产出 PDF + 1600px 高清 PNG
$PY ~/.workbuddy-ai/skills/shenlun-daily/scripts/build.py content.json

# 指定输出根目录
$PY ~/.workbuddy-ai/skills/shenlun-daily/scripts/build.py content.json -o 工作空间根目录
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `-o` | `.` | **输出根目录**（不是期文件夹）。脚本会在其中按 `file_stem` 自动新建一期文件夹 |
| `--ratio` | `2:3` | `2:3`（210×315，小红书长图）｜`a4`（210×297）｜`3:4`（210×280） |
| `--px` | `1600` | PNG 宽度。`1600` 高清（默认）｜`2400` 印刷级｜`1080` 小红书标准宽｜`0` 不缩放（1903px） |
| `--flat` | — | 不建子文件夹，直接输出到 `-o` 目录（一般不用） |
| `--no-pdf` / `--no-png` | — | 只出一种 |
| `--keep-html` | — | 保留中间 HTML，改版式时用 |

### 交付物固定三件

跑一次，自动新建一个文件夹，里面**只有**这两样（`--keep-html` 时多一份 html）：

```
2026广东申论日报-第01期-再造广东向新而行/
├── 申论日报-第01期-再造广东向新而行.pdf     ← 矢量，可打印、可检索
└── 申论日报-第01期-再造广东向新而行.png     ← 1600×2401，小红书用
```

- 文件夹名 = `file_stem`（`年份+地区+系列+期号+标题`）
- 文件名 = `file_name`（省略则同 `file_stem`）
- 同名重跑会覆盖，不会堆出 `(1)` `(2)`；上一轮残留的 html 会自动清掉

跑完会先打**出厂自检表**，再打**版式参数**，最后一行是交付目录：

```
── 出厂自检 ──
  ✓ 结构 · 原文段数：9 段
  ✓ 一致性 · 右栏金句出自原文：全部命中
  ✓ 编号 · 段落 1..N 连续：是
  ...
[版式] 210×315mm  基准字号 2.14mm ≈ 6.1pt  填充率 99%  左栏 98% / 右栏 99%
[PNG] …/申论日报-第01期-再造广东向新而行.png  1600×2401
[PDF] …/申论日报-第01期-再造广东向新而行.pdf
[交付] …/2026广东申论日报-第01期-再造广东向新而行
```

**看两行就够了**：自检有没有 ✗；左右栏百分比是不是都在 95% 以上。
某栏低于 85% → 那一栏补两三行。自检有 ✗ → 按提示改内容，不要改脚本。

## 二、三步做完一期

**第 1 步 · 切段。** 读源文，按 `references/CONTENT.md` 第一节的九段骨架切：
`起 → 转 → 分论一 → 分论一续 → 分论二 → 分论三 → 分论四 → 论据 → 收尾`。
功能位顺序不能乱，名词可以换。

**第 2 步 · 写 content.json。** 复制 `examples/` 里那份改，字段见第三节。

**第 3 步 · 跑脚本，看 PNG。** 自检全绿 + 两栏都 ≥95% 才算完。

## 四、四个坑（都踩过，别再踩）

**1. 右栏金句必须逐字出自左栏正文。**
自检会拿 `quote` 前 10 字去左栏正文里做子串比对，命不中就报「未命中 第N条」。
原稿第 7 条就是编的（「改革不是一次性的冲锋」正文里根本没有），所以这条自检是硬性的。

**2. 编号必须 1..N 连续。**
段落、右栏条目、金句带三处编号各自独立从 1 起。原稿金句带从 3 开始编，是模板计数器没重置。

**3. 图例只列页面真用到的标记。**
`legend` 里写几个，正文就必须真用几个。承诺了却不用，等于自己打自己脸。

**4. 别用 `scrollHeight` 量内容高度。**
父元素 `overflow:hidden` 且内容较矮时，`scrollHeight` 恒等于 `clientHeight`，
自适应会误判"刚好满"并把字号锁死在最小值。已在 `FIT_JS` 里改成量子元素
`getBoundingClientRect().height`，改脚本时别改回去。

## 五、交付（固定三条，不用每次问）

1. **一期一个文件夹，脚本自动新建。** 在**当前工作空间**根目录跑，`-o` 指工作空间根，
   脚本按 `file_stem` 建 `年份+地区+系列+期号+标题` 的文件夹。
2. **每个文件夹里只有两件**：`.pdf` + `.png`。PNG 默认 1600px 宽（高清），
   PDF 是矢量、可打印可检索。中间 HTML / 临时文件脚本自动清。
3. **交付前逐页目检 PNG**：页脚压正文、粉条压行、两栏底部不齐、金句标签错位，
   这些机器查不出来，眼睛能。

> 例外：要印刷级位图时加 `--px 2400`；要压体积给微信传时加 `--px 1080`。
> 两者都还是同一套排版，只是导出尺寸不同。

## 六、改版式

只动 `scripts/style.css`。所有尺寸用 mm，所有字号写成 `calc(var(--fs) * 倍率)`，

**早报特有的三条硬规矩**

1. **时政一条都不许编。** 会议名、文件全称、数字、时间必须能追到来源和日期。
   检索不到就当天空缺，宁可少一条。页脚固定写「时政以官方通稿为准」。
2. **每条时政必须有 `point`。** 没有「这条怎么用」的时政，等于没写。
3. **广东素材的判定标准**：这句话能不能直接搬进广东卷作文当论据？不能就换一条。

自检会查：时政 3—6 条、每条字段齐全、标题 ≤24 字、会议 ≥1 个且每个 ≥2 条要点、
广东 ≥3 条、金句 1—3 句、数字 4—8 个、编号连续、摘要总字数 450—1200。
